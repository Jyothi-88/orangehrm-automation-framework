# OrangeHRM Automation Framework

A Selenium Java automation framework built for the OrangeHRM web application using industry-standard automation practices.

## Project Objective

The objective of this project is to build a maintainable and scalable UI automation framework using Selenium WebDriver, Java, Maven, TestNG, Page Object Model, reporting, logging, and CI/CD integration.

This project is being developed as part of my QA Automation Bootcamp and portfolio.
